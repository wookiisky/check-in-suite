# 任务、打卡与查询

## 关键概念

任务定义“做什么、何时出现、一天最多做几次及每次奖励”；打卡保存一次实际完成。记录所属的台北业务日期用于次数、权限和统计，创建时间表示实际操作时间，两者不能混用。全局日期与存储约定见[数据与存储](../SYSTEM/STORAGE.md)。

新记录保存任务名称、图标和双币奖励快照。后续改名、调价、停用或删除任务都不改写这些历史事实。账户余额来自实际奖励、回收和消费流水，前端不根据页面记录自行计算余额。

## 任务与类别配置

类别支持新增、改名和删除；仍含未删除任务的类别须先移动或删除任务，不能隐式批量删除。任务名称不能为空，每周至少安排一天，次数上限为正整数，奖励为非负整数。字段和值域查 API 和当前配置。

任务管理可直接开启、关闭任务，默认隐藏关闭项并提供显示选项。关闭后普通打卡和管理补录均不能为其新增记录；既有记录仍可查看、编辑内容和删除。重新开启后，仍需满足星期安排和次数限制。

配置变更只影响后续新建记录。降低次数上限不删除已有记录；当天已用次数达到或超过新上限时拒绝新增。删除任务保留历史身份、记录、统计和原奖励。任务排期历史用于[成就计算](ACHIEVEMENTS.md)，管理补录仍按当前任务配置校验，两种用途不能混为一套规则。

任务可关联营地活动，关联和资格规则由[营地专题](ISLAND.md)维护。

## 今日任务与创建

今日任务必须同时满足：未删除、已开启、星期匹配且今天仍有剩余次数。任务区始终表示服务端的今天，不随上方浏览的日期或周变化。卡片展示图标、名称与本次双币奖励，整卡支持鼠标和键盘操作；达到次数上限后移除，已完成记录继续展示。

任务按类别筛选，空类别不占主要区域。“当天没有安排任务”与“当天任务全部完成”是不同状态。删除今天的记录释放次数后，仅当任务仍符合当前安排时重新出现。

用户在弹窗确认时才提交打卡。每条记录可有一张照片、一段文字和一段录音，均可留空；附件先上传，业务提交按媒体 ID 关联，具体生命周期见[媒体专题](MEDIA.md)。取消或关闭弹窗不占次数、不发奖励。

创建在一个短写事务中复核权限、恢复相同请求的成功回执，再检查日期、任务版本、星期、次数和附件状态。记录、奖励流水、钱包、媒体关联、成就变化和成功回执一起提交；任一步失败都不能只发奖励或只占次数。

普通入口只创建今天的记录，并携带用户确认时的业务日期。午夜后请求返回日期变化时保留草稿、刷新今日状态并重新确认。任务在弹窗打开后被修改时，显示最新配置并要求重新确认，不能悄悄按新奖励提交。

提交中禁用重复确认。结果未知时保留原请求与幂等键，按[HTTP API](../SYSTEM/HTTP_API.md)恢复；普通失败保留草稿。写入已成功而后续刷新失败时只重试读取，不能再次新建。新建草稿与每条记录的编辑草稿分别保存，处理其中一份不能清除另一份。

## 编辑、删除与补录

普通入口只能编辑、删除今天的记录；管理入口可以处理今天及过去的记录，但不能新增未来记录。服务端按实际业务日期判断权限，不能依赖浏览器时区或旧页面按钮。

内容编辑只替换文字、照片、录音并推进记录版本，不改记录身份、业务日期、任务、奖励或已用次数。“重新打卡”采用同一条记录的内容编辑规则。版本冲突时保留草稿，取得最新记录后由用户重新确认。

删除前展示将回收的原奖励。删除在同一事务中标记记录失效、清空内容与附件引用、按原奖励回收双币，并重算成就。删除后记录不参与次数、列表或统计；余额不足也允许回收，已购买物品和奖励保留。例如先获得 10 金币、花掉 8，再删除原记录，余额成为 -8。

重复删除在当前鉴权通过后返回已删除的成功状态，不再扣款。已删除状态先于普通历史日期限制识别，因此删除成功但响应丢失时，跨日重试仍可恢复结果。未删除的历史记录仍只能从管理入口删除。

管理补录按目标日期检查非未来、当前任务开启状态、星期安排和当日次数，并按当前配置生成新快照。纠正日期或任务采用“删除旧记录，再补录”的两个操作，不伪装成保留奖励的编辑。删除成功但补录失败时，旧记录保持删除，保留补录草稿并明确提示当前结果，不做隐式补偿。

## 日、周与月历

日视图默认今天，只展示所选日，支持前一天、后一天和今天。周视图以周一开始，桌面七列、手机七天纵向分组，空日期也保留。记录展示快照图标、名称、操作时间和附件标记；普通列表、详情及编辑隐藏已完成记录的奖励，管理记录与删除确认保留奖励供核对。

月历按业务日期汇总有效记录次数，图标过多使用数量摘要。桌面七列，手机按周纵向显示日期；点击日期再读取完整记录。过去日期普通入口只读，未来日期可查看为空但不能创建。所有列表排除已删除记录，空分组不生成虚构记录。

营地的任务、次数和钱包必须来自同一读取快照，不能拼接写入前后的结果。页面切换、写成功及跨日加载规则见[界面专题](INTERFACE.md)。

## 统计口径

统计以任务稳定 ID 分组：每条有效记录计一次，同一天多次分别累计，补录按所属日期计数。内容编辑不增加次数，删除记录不计入；停用和删除任务不抹去历史贡献。明细可使用任务当前名称，记录详情继续显示名称快照。

摘要是总次数和有记录的日期数，明细按次数降序、同次数按稳定任务 ID 排序。横向条形图与带数值列表使用同一结果，摘要与明细来自同一读取快照；金币不能代替打卡次数。

默认本月；本周从周一到今天，本月从月初到今天，近七天包含今天及此前六天，近三十天同理。自定义范围包含两端，开始晚于结束或结束晚于今天时拒绝。无数据返回零与空结果，不填充示例成绩。

## 验证边界

次数竞争、奖励回滚和读取一致性由真实 SQLite 测试证明；响应丢失、跨日、草稿与刷新失败需验证最终可观察结果。附件、成就、营地资格受影响时同时核对相应专题。测试候选列在元数据中，执行范围遵循[测试指南](../ENGINEERING/TESTING.md)。
