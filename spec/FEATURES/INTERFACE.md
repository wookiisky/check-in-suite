# 界面、家庭留言与反馈

## 页面分工

应用名称为“成长营地”。“每日打卡”是任务和记录入口，并展示余额、角色与家庭留言；“我的营地”进入可布置的全屏场景。月历、统计、商店和成就有各自页面，管理入口负责账户、任务、历史记录和商品等配置。界面继续使用“打卡”“月历”“统计”“商店”等可理解的名称，避免用游戏术语代替实际功能。

产品名称与页面文案通过配置资源提供。内部接口、会话 cookie、数据库路径、服务名称和稳定素材标识继续沿用原有身份，改名不迁移这些数据或撤销会话。

本专题维护跨页面规则和每日打卡页中的家庭互动。任务与统计口径见[打卡](CHECKIN.md)，装扮和兑换见[商店](SHOP.md)，全屏场景与离开草稿规则见[营地](ISLAND.md)，授权见[账户](ACCOUNT.md)。各能力特有规则只在对应专题维护。

## 加载、提交与草稿

会话、姓名、钱包及业务实体以服务端为事实来源。页面只保存展示状态，不在不同组件中复制余额计算；打卡、购买和删除等操作等待服务端成功后才显示成功结果。

通用加载有三类触发：进入页面或改变筛选、写成功后刷新受影响区域、发现跨日后刷新今日状态及权限。普通页面不轮询、不监听焦点或联网事件自动刷新，也不建立标签页广播或跨设备同步。营地活动资格的恢复前台检查按营地专题处理。

台北午夜和恢复可见时根据服务端时间差检查业务日期；未跨日不自动重载通用页面。写入仍由服务端校验日期，返回日期变化时保留草稿并重新确认。请求取消或序号用于防止迟到结果覆盖新筛选，失败只影响对应区块。

编辑草稿、媒体预览与录音由对应弹窗持有，普通刷新不重置。未保存离开时确认放弃；失败保留输入并给出重试。结果未知的写入保留原始请求和幂等键，不能仅因草稿变化就换键重发，恢复语义见[HTTP API](../SYSTEM/HTTP_API.md)。

成功写入后的读取失败应提示刷新重试，不把已提交操作当作失败再写一次。版本冲突时展示变化、保留本地草稿，取得需要的最新信息后再由用户决定重试。权限失效时清除对应管理状态。

## 阅读与操作

界面采用极简、大字的游戏化卡通森林冒险风格，图片与图标表意优先，去除重复文案与说明性小字；图标使用既有彩色实心 SVG，保持形状、圆角卡片与按钮阴影的一致性，文字在复杂场景上仍需可读。

既定布局基线为 iPhone 14 竖屏 390 CSS 像素，手机通过纵向排列和换行保留大字，不缩小成桌面布局。普通页面与弹窗的可见文字至少 22 px（主要文字 22–24 px、标题 32–40 px），仅管理界面可使用 18 px 的辅助文字；独立操作目标至少 56 × 56 px。页面保留用户缩放能力，不以设备模拟结果宣称真机通过。

桌面每日打卡页的日视图为记录、任务在左，角色及家庭留言在右；周记录可以跨宽度展示。手机先显示记录与任务，再显示角色和留言。月历和周记录的具体布局见打卡专题。

键盘可操作，焦点可见，表单有可见标签，字段错误就近呈现。弹窗在可视高度内滚动，考虑安全区和软键盘；打开时焦点进入，关闭时回到触发元素。图表提供等价文字列表，状态不能只靠颜色区分；图标操作提供可访问名称。

系统或账户要求减少动效时，移除位移、缩放、入场和常驻运动，保留静态文字、奖励数量及操作能力。动画不得阻挡下一步操作或要求用户等其结束。

## 家庭留言

留言属于当前账户，登录后可新增、读取和删除纯文本，显示创建时间；不提供公共访问、回复、点赞或通知。去除首尾空白后不能为空，长度按服务端生效限制检查。删除前确认，其他区块刷新不能清空输入中的文字。

创建与幂等成功回执在同一授权事务提交。重试返回原留言身份，不重复插入；原留言后来被删除时也不因重试复活。删除可重复调用，不影响打卡、钱包或其他业务事实。

列表按创建时间和稳定 ID 倒序分页，游标包含两个排序值，避免同一时间的多条留言重复或遗漏。读取和写入都检查当前会话，客户端不能指定所属账户或创建时间。

## 音乐与操作反馈

背景音乐默认关闭，须由用户主动开启；背景音乐与操作音效分别控制，减少动效也有独立开关。音频播放受浏览器用户手势约束，激活失败允许之后的手势重试，不在恢复页面时自动补播。

打卡、购买、换装和营地布置保存成功后播放对应短旋律；普通点击、拖动及角色自主活动不发声。成功事件只在服务端确认后触发，普通刷新不重放。关闭音效立即停止未结束的操作音；录音及后台状态停止声音，录音期间不播放操作音效。

声音实例跨普通页面切换保留，避免重建音频上下文。音乐恢复仍遵守用户此前偏好和浏览器播放条件；功能失败或拒绝授权时不能用声音掩盖错误。

## 打卡奖励反馈

奖励反馈读取成功回执中的金币与钻石快照，不从余额差推算。记录身份用于去重，成功恢复或普通刷新不能重复播放已消费的反馈。

每份奖励对应一个装饰图标，两种货币各最多显示 50 个；超过上限仍展示完整实际金额，零奖励不显示对应图标。奖励越多效果更密集，但不延长操作等待；钻石使用较大图标、独立高亮和一次扫光。减少动效时只保留静态高亮与金额，关闭偏好后不补播旧动画。

音效按实际数量增加收集节拍，两种货币各最多 8 拍，并在短动效窗口内结束；密集播放降低单音增益。金币采用清脆短音，钻石带余韵和上行尾音；两种奖励都为零时保留简短成功音。静音、录音和后台状态不播放或补播奖励声音，新反馈替换尚未结束的旧反馈。

## 验证边界

组件测试覆盖草稿保留、焦点、过期响应和偏好；浏览器测试检查真实布局、可访问名称、操作后显示与音频渲染。系统后台和设备硬件能力须明确区分于模拟事件。测试选择及历史验证限制见[测试指南](../ENGINEERING/TESTING.md)。
