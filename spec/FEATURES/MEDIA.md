# 照片、录音与媒体生命周期

## 职责与输入

媒体模块保存打卡使用的一张照片和一段录音。上传产生可引用的私有文件，不创建打卡、不占次数、不发奖励；文字和媒体 ID 最终在[打卡事务](CHECKIN.md)中保存。照片、文字和录音均为选填，某种采集方式不可用时仍可完成打卡。

照片支持 JPEG、PNG，提供拍照及选择现有文件两种入口，并允许预览、替换和移除。录音按运行时能力选择 WebM/Opus、Ogg/Opus 或 MP4/AAC，最终以服务端实际文件探测为准。首版不把 HEIC、视频、动画图片或用户 SVG 当作默认支持的输入。

体积、像素、时长和文字上限由服务端配置及会话返回值决定，前端使用实际生效限制。浏览器预检只减少无效提交，不能替代服务端解码和探测；原型的限制与模拟录音不构成正式行为。

## 浏览器采集与草稿

录音由当前弹窗拥有。采集状态明确区分空闲、请求权限、录音、等待最后分片和错误；停止后等待完整文件到达再交给试听与选择界面，不能把半段录音当作成功结果。试听可播放、暂停、重录和移除，移除录音不影响照片与文字。

录音时间由单调时钟计算，达到服务端时长上限时请求停止，不通过累计定时器次数估算。编码格式声明支持后仍可能创建失败，前端继续尝试可用格式或给出可恢复错误。

拒绝麦克风权限、设备不可用、格式不支持和录制失败分别反馈。页面进入后台或音轨意外结束时结束本次采集并提示中断，允许重录，不承诺后台或来电时完整录制。关闭弹窗、卸载组件或迟到的权限请求完成时都必须释放音轨；未保存的预览资源按草稿生命周期释放。

采集期间暂停声音，结束后按用户的声音偏好恢复允许播放的内容。录音需要浏览器提供安全上下文和麦克风权限；部署入口要求见[运行手册](../ENGINEERING/OPERATIONS.md)。自动化浏览器结果不能证明手机硬件兼容。

普通数据刷新不能重置附件与文字草稿。离开未保存内容前确认放弃；新建与各条编辑记录的草稿分别持有资源，释放其中一份不能破坏另一份。

## 上传与关联

1. 用户确认提交后，前端先上传尚未成功的附件；部分失败时保留表单，只重试失败部分，已取得的媒体 ID 可继续使用。
2. 服务端流式写入临时文件，在数据库事务之外校验内容。照片检查实际格式、像素和体积，按 EXIF 方向变换像素、缩放、去除原始元数据后重编码。音频使用受控的 `ffprobe` 探测实际容器、编码与时长，并限制执行资源。
3. 文件使用服务端生成的键，在同一文件系统原子重命名为不可变正式文件。必要同步和数据库登记成功后才返回上传成功。
4. 打卡事务检查媒体类型、状态、引用和保留期，再将文件关联到记录。新引用只能使用尚未撤回且未过期的 `ready` 文件；编辑可以保留该记录原有的 `attached` 文件，不能借此引用另一条记录的附件。

文件系统与 SQLite 不共享事务。文件已落盘但登记失败时不能返回成功，遗留文件由孤儿清理处理。上传期间发生凭据撤销仍须拒绝失效授权，不能仅依赖请求开始时的登录检查。

## 状态、私有读取与撤回

| 状态 | 业务含义 |
| --- | --- |
| `ready`，未撤回且未过期 | 可由当前账户预览，并可被一条记录新关联 |
| `attached` | 属于有效记录，保留期间随该记录私有读取 |
| `ready`，已写解除引用时间 | 已撤回，立即禁止读取与再次关联，等待物理清理 |
| `deleting` / `deleted` | 禁止读取和关联；删除失败可继续重试 |

读取经过登录校验，并检查引用或临时预览资格；返回正确媒体类型及私有缓存策略，音频支持 Range。客户端不能指定原始路径、目录或存储文件名。

替换附件或删除记录时，在业务事务内解除旧引用并记录撤回时间。取消未关联上传也使其立即失去读取资格；物理删除延迟不代表仍可访问。仍被有效记录引用的媒体不按临时上传保留期删除。

## 结果未知与清理恢复

写入结果未知时，前端保留原请求需要的媒体，先按原幂等键核对，不主动撤回。保留期不会因核对延长；恢复时若上传已过期，仍先确认原命令是否成功：成功则恢复结果，未成功且媒体失效则明确失败，再允许重新上传。

清理先在短事务中确认无有效引用且超过保留期，将文件标成 `deleting`，阻止新关联；事务外删除物理文件，成功后标成 `deleted`。文件已不存在可视为删除成功，其他失败保留状态，下轮或重启后继续处理。

孤儿扫描只检查服务生成的临时文件及 UUID `.media` 文件，不递归、不删除无关文件或内置素材。扫描依据文件时间、进程内在途登记和数据库登记判断，删除前再次核对；保留期须长于允许的上传和探测时间。

媒体和上传临时目录不能与数据库所在目录相同，包含符号链接指向同一目录的情况。正常的数据库、媒体、临时文件分目录布局允许首次启动时目录尚不存在。容量与故障处理步骤见[运行手册](../ENGINEERING/OPERATIONS.md)。

## 验证边界

真实图片和音频样本证明服务端格式、方向与时长处理；真实文件目录和数据库证明引用竞争、撤回后不可读及清理恢复。采集测试与浏览器录制测试证明对应环境的编码及生命周期，不替代手机真机验收。测试候选列于元数据，按[测试指南](../ENGINEERING/TESTING.md)选择。
