# 商店、装扮与奖励

## 职责与所有权

商店把当前可用金币和钻石兑换为装扮、营地物品或家庭约定的奖励。账户余额代表可购买数量，不等于累计获得数量；后者用于统计和成就。价格、库存、上架状态由管理页维护，素材与能力由受控资源目录定义。

商品是当前报价，订单是成交快照。订单保存购买时的名称、类型、素材、说明和价格；下架、删除商品或删除原打卡记录，都不撤销已取得的所有权。首版不提供退货、转赠或审批。打卡回收与负余额规则见 [打卡](CHECKIN.md)，事务与流水一致性见 [存储](../SYSTEM/STORAGE.md)。

## 页面与分类

商店一级为角色装扮和营地。角色装扮按身体与穿戴部位筛选，营地按物件目录分类，并将场景单列。物件没有分类时归入其他。两组都能查看全部商品。切换分组重置子分类和页码。分类不从名称或资源标识前缀推断。商店可直接跳页，先应用分类和已拥有规则，再计算总数和分页。已拥有的同款商品不进入新浏览结果，包括原报价允许重复购买的物件。称号和文本奖励不在商店陈列。

装扮是独立页面，可从主导航或商店进入。商店直接显示分类栏，一级分类右侧提供装扮入口。装扮页左侧按身体和六个部位选择并分页，右侧预览可旋转形象。基础身体只有人形和骷髅，使用相同身体比例、骨架和绑定姿势。穿戴按身体标准与骨架校验，能够在兼容身体之间复用。装扮库存读取完整已拥有数据，再按部位和页码展示。

营地物件与场景在营地使用，角色装扮在装扮页使用。应用没有独立的背包页面或背包弹层。配置页保留其独立的商品筛选与读取方式。

## 购买与失败恢复

服务端以 `APP_ENV=development` 启动时，装扮旁显示「一键购买」，`npm run dev` 默认开启。登录后点击即可为当前账户补齐角色装扮与营地两组所有已上架的商品，覆盖全部分类和页码，也包括售罄报价。同款只发一份。服务端在同一事务中写入零价订单和零额流水，金币、钻石与库存数量保持原值。再次点击只补齐仍未拥有的商品。其他环境调用接口返回 404。

商店商品卡片在缩略图上方显示商品名。购买按钮展示金币价格，需要钻石时也展示钻石价格，两种价格都配有对应图标。按钮的无障碍说明包含价格，以及适用的已拥有、售罄或余额不足提示。

确认框展示商品、两种价格和购买后余额。两项价格都为零表示免费，两项都非零则同时支付；有限库存为零时售罄，不限量与零库存不同。

一次购买在同一事务内核对会话、幂等结果、商品版本、钱包版本、库存及重复购买资格，随后写订单、双币流水、钱包、库存和成功回执。任何一步失败都不能留下部分扣款或部分订单。免费购买也保存订单和零金额流水。

两种余额都必须满足 `余额 >= 对应价格`，因此任一种余额为负时，即使该币价格为零也不能购买。商品或钱包在确认后变化时，重新读取并让用户再次确认；结果未知时沿用原请求恢复，规则见 [HTTP 协议](../SYSTEM/HTTP_API.md)。

场景作为独立商品购买，稳定场景身份保留在订单快照中。同一场景的不同报价共享永久资格，只能购买一次；下架或删除商品不撤销资格和布局，已售报价不能改换场景身份。购买只解锁空间，不自动进入、不赠送房屋或复制家具；摆放与搬运规则见 [营地](ISLAND.md)。

普通永久商品不能重复购买；文本奖励允许重复，每次产生独立待兑现订单。营地物品是否允许重复由物品定义决定，每次购买仍只取得一个实例，其摆放规则见 [营地](ISLAND.md)。

购买成功后关闭确认框并显示结果。成功回执立即更新余额，页面保留当前分类和页码。刚买到的商品留在当前页置灰，卡片显示「已拥有」并禁用购买按钮。购买后翻页按同一次浏览的商品顺序计算边界，避免漏掉后一页的第一件商品。再次浏览时按当前所有权筛选。购买不会自动装备、摆放或切换场景。未解锁的场景入口直接打开商店的场景分类。营地读取完整库存，不以商店当前页作为库存。

## 三维外观保存

基础人形免费使用，基础骷髅通过角色商品购买并永久拥有。职业与战损外观不再作为独立角色出售，职业衣物按部位作为穿戴商品购买。角色商品与订单使用稳定身体身份；模型加工版本与身体所有权分开，不能因重做模型再次收费。同一身体即使有多个报价，也只能购买一次；商品下架或删除不撤销已有资格，已经售出的角色商品不能改指另一个身体。

取得基础身体后可以使用其六槽默认项，不另扣费用，也不伪造服装订单。其他脸部外观、头饰与职业衣物独立购买，不随购买骷髅自动赠送整套职业装。选择另一身体先回到其默认穿着，只改本地草稿，保存时和六槽一起提交，取消不修改已保存外观。

基础人形默认穿米白圆领背心和深灰平口内裤，鞋子为空。背心和内裤分别占上装、下装槽，换上该部位的其他衣物时一并替换。原绿短袖、绿短裤和翻边皮靴分开出售，穿戴时需要对应订单。

米白背心、披风和披肩可以换色。三件共用米白、黑、红、橙、黄、蓝、绿和棕色预设，披风默认红色，披肩默认棕色。穿上其中一件即可在该部位试色，颜色随整套外观保存，其他页面读取保存后的颜色。换一件衣物或缺省颜色字段时，使用所穿衣物的默认颜色。服务端以该槽实际选中的衣物和目录预设校验颜色，校验失败时整套外观不保存。

八个方形色块在同一行均匀分布，并随可用宽度缩放。颜色名称显示在色块内部，当前选项以高亮边框标记。极窄空间下可横向滚动。

已取得身体的默认穿戴也可以用于其他兼容身体。它们没有独立购买订单，使用各槽明确的免费穿戴身份保存。同槽的免费来源和购买来源不能同时指定，也不能借免费来源选择尚未取得的身体默认项或付费商品。默认项和其他免费项直接显示目录名称。可用的不穿戴选项以圆斜杠图标展示，排在该部位的衣物之前。

形象只替换脸、眼鼻嘴、耳及裸头皮或头骨，不改变身体和手脚。头部包含发型、帽子、头盔、兜帽面巾和头部中箭，同一时间只选一件；帽子附带头发时作为一件组合商品，但不能带入来源人物的脸。头部空项显示所选形象的裸头；中箭跟随头部骨骼，装备后替换帽子或发型，本次不包含身体插箭、破脸或缺骨。背部单独选择披风、披肩或箭袋，同一时间只选一件，也允许卸下。

形象目录保留四款。微笑脸和裂纹骷髅分别随基础人形、基础骷髅解锁，骷髅和红纹骷髅可单独购买。微笑脸使用连续的近球形头部。头饰通常保留完整头部轮廓，贴合的头盔可按覆盖定义隐藏头皮，自带眉毛的头饰也可隐藏微笑脸的眉毛。

骨骼和裸露皮肤属于基础身体，不能混入衣物商品。源模型缺少的身体部分需要在素材制作时补齐，不把重复脸、重复衣物、空部件或来源缺失而补上的默认裤鞋当作新商品。

基础人形的躯干、肩臂和腕掌使用离线制作、轮廓连续的低面数网格，去掉旧支撑网格中的衣袖、护腕和固定手套轮廓。身体保留既有身高、骨架、关节位置与穿戴分区；原款手套和护手随对应上装穿脱。身体简化不新增运行时碰撞或衣物求解，裸身接缝和穿衣动作须分别验证。

基础身体还须在不同脸型及动作中保持颈部和腿部连接。源模型由服装遮住的缺段在离线制作时补齐；检查既有共用顶点不开裂，不能代替检查两个原本不相接的部件。背部穿戴与默认上衣一同检查，闭合披肩被上衣穿出不能当作来源开口接受。发型只有在能够覆盖相应区域时才隐藏脸型的裸头皮。

人形腰髋只保留裸身支撑，原裤壳、腰扣和侧袋属于下装，不能染成肤色后固定在身体上。骷髅腰部在同一骨架上离线适配兼容衣物，保留来源骨面的拓扑、UV和原蒙皮；不能用扩大全部衣物掩盖身体轮廓不匹配。补齐的人工骨关节须在实际动作中保持连接，新增股骨的髋端跟随髋球，膝端保留大腿绑定，不能只凭静止接合认定完成。

覆腰上装与下装共用身体标准的腰线。下装在腰口局部留出搭接量，偏高的衣摆在离线制作时向腰线贴合。必要时让接合边逐步过渡到相近的蒙皮，使走路和坐下时腰口能随衣摆一起移动。腰带、扣具和挂件由完整的下装提供，搭配其他上装时仍随下装显示。裤腿、袖口与衣领保留各自的长度。空上装和原款开襟仍可露出身体。

三维外观使用独立的读取与整套保存接口，一次取得人物定义、六槽服装、完整已购库存和已保存选择，不受商店订单分页影响。每个部位在购买来源和免费来源均为空时选择当前人物的默认项；缺省的必填字段、空字符串、未拥有实例、错误部位，以及不适配身体或骨架的定义均不能保存。称号和徽章不进入人物骨架或六槽版本。

外观保存携带独立的预期版本。服务端在同一写事务中复核会话、当前版本和全部六槽，再一次写入并递增版本；任一验证或提交失败都不能留下部分外观。版本冲突不覆盖已保存内容，客户端应保留草稿并读取当前状态。新增购买只增加库存，不递增外观版本，因此同版本读取仍可能包含新服装。

三维服装使用 `wearable` 商品类型，购买在原有扣款事务中将稳定服装身份复制到订单。商品下架或删除不撤销已购资格；已售商品不能改指另一服装定义。默认服装由人物定义提供，取得人物后可用，不能另外创建为服装商品；初始化只提供替代服装的报价。旧二维单槽、自由饰品、整体动物形象、背景与特效接口已退出。

背部槽的披风与披肩各有一款。背部商品和穿戴按当前目录身份处理。

共享人物组件与六槽编辑器可在 `/character-preview.html` 独立验证，使用正式登录、目录、库存与保存接口。编辑器打开时读取当前外观，选择只修改本地草稿；取消丢弃草稿，保存期间冻结选择与关闭，成功直接发布完整返回快照。共享层接受同版本新增库存，并防止保存前发起的迟到读取覆盖新状态。

装扮编辑器支持水平 360° 查看。鼠标主键拖动或单指横向滑动可旋转人物，纵向滑动保留页面滚动。左右旋转按钮每次转动 45°，恢复视角按钮回到初始朝向。相机俯仰与缩放固定。角度只属于当前预览会话，换装、保存和模型重试保留朝向，关闭后重开恢复初始视角。旋转不修改草稿或外观版本。减少动效时，手动旋转仍即时更新画面。

模型、身体遮盖与动作由共享人物模块处理，各视图持有独立骨架和播放器。一个身体或服装节点可以包含多个材质网格，显隐与跨人物重绑覆盖该节点的全部网格，保留原有材质和蒙皮。穿戴定义可以显式声明可被其他部件覆盖的区域，例如帽子隐藏所选形象的头皮而保留脸；不能依靠节点名称猜测身体部位。所选资源全部准备好后才一次替换当前人物；等待或失败保留上次已显示的人物，取消和迟到结果不能留下未使用实例。加载缓存拥有源几何、材质与纹理，最后一个引用释放后再销毁，单个预览卸载不能影响另一处人物。减少动效时显示动作首帧，隐藏或暂停不推进时间，恢复时丢弃累计时间差。

可换色服装在目录中声明可染材质和默认颜色。不同配色复用同一 GLB。渲染器只调整当前人物实例的材质副本，骨架、网格和缓存中的源材质仍可供其他人物使用。

保存结果和人物显示状态分别反馈。已保存后出现模型错误时保持保存事实，只重试显示。版本冲突保留六槽草稿，先展示当前已保存外观，再由用户选择保留草稿继续编辑或使用当前外观。网络断开等未知结果保留原请求，读取当前状态核对；仍是原版本时可重试原请求，不能擅自换成较新版本覆盖。离开装扮页不撤销已发出的保存，重进页面继续核对。

## 称号与奖励接口

应用使用已获得的成就作为人物旁的文本，规则见 [成就](ACHIEVEMENTS.md)。原购买称号仍可通过既有装备接口读取和设置。服务端继续核对称号类型和订单所有权，称号与三维外观分别保存。

商店浏览界面移除文本奖励，应用也移除奖励兑现入口。既有兑现接口继续在事务内复核会话、凭据版本和订单状态。每次兑现单独验证管理密码，重复兑现已处理订单只返回当前结果。

## 素材与兼容边界

商品素材来自内置目录，不提供上传入口。目录保留普通图标、称号、奖励、徽章、三维模型、动作、服装与营地缩略图。免费属性仅用于免费营地缩略图，默认服装另按身体定义校验；管理页只能选择适用于商品类型的素材。

素材制作先输出独立候选，完成分类检查后再显式应用正式目录。加工类型与商品分类分别管理；来源组件归属、候选依赖及应用方法见[运行手册](../ENGINEERING/OPERATIONS.md#素材分类候选与应用)，检查的证据边界见[测试指南](../ENGINEERING/TESTING.md)。

素材以不可覆写的版本标识安装到独立持久目录。名称、类型、格式、来源与许可等元数据和素材字节都属于该版本，修改其中任何内容都须采用新标识。发布目录被替换后，历史订单仍可读取已安装素材；退役素材可以从源码和当前可选目录移除，持久目录中的旧素材继续保留。已购物品可以通过稳定物品身份获得新增的营地能力，成交事实保持原样。

三维人物与服装使用独立的版本定义。人物定义登记身体、骨架绑定规格、模型、身体分区、六槽默认项和整理后的动作；服装定义登记所属部位、适配身体与骨架、实际网格及覆盖区域。定义不代表购买或装备，所有权仍由订单提供。默认项不需要购买，也不通过将缩略图标为免费来实现。

三维模型与动作以自包含的 GLB 安装，文件中的纹理不依赖相对外链。它们复用登录后的同源素材路径，响应类型为 `model/gltf-binary`，不进入管理页的可选图片目录。服装卡片使用从实际模型渲染的透明 PNG；该缩略图属于 `wearable`，不沿用二维自由饰品的穿戴槽或后层图片属性。原始包、Blender 工程与原始 Mixamo FBX 不进入运行下载包。

三维资源元数据分别保留官方来源与许可。KayKit 人物与 KayKit、Kenney 建筑和摆设使用各自的 CC0 资源，Mixamo 补充动作按其项目使用条款登记，不能因为目标骨架来自 KayKit 就把整个动作标为 CC0。资源整理和缩略图重绘见 [运行手册](../ENGINEERING/OPERATIONS.md#三维资源制作与安装)。

官方免费三维资源按固定的包清单整理，保存来源、下载版本、原包与产物校验值和许可依据。相同模型的不同交换格式不重复上架；独立外观保留。可选人物统一到 KayKit Medium 身体标准，实际整理骨架、绑定姿势、服装切面与身体遮盖，不能只缩放根节点就认定衣服兼容。脸与头饰分别处理，不用换整个头部冒充换发型。Kenney 人物及其专属穿戴不进入正式目录和发行包，Kenney 建筑、家具与动物摆设仍按原规则保留。动物、四足等非人形资源只作为完整独立摆设使用。

完整物件库与本次上架范围分开维护。先保留所有能够独立展示的完整物件，再按海边营地和家庭生活场景选择代表款，补足现有用途，同种物件尽量不重复，避免用配色和细微变体填充商品数量。未选入的物件仍保留来源和加工记录，不进入本次商品、正式模型目录或运行下载包。

单面墙、屋顶片、门框、地板砖、道路拼片等搭建零件，以及骨架、人体碎片和贴图依赖不独立成为商品。包与模型清单区分已整理入库、本次选入、因范围排除、待审核和转换失败；下载或登记不代表已经能购买、装备或摆放。

商品目录支持搜索、来源包筛选和分页，卡片使用模型缩略图，模型按需加载。订单来源筛选与筛选选项使用同一解析规则：优先保留受控素材的来源，历史缩略图退役或缺少字段时按订单中的稳定人物、物品身份补齐，不改变成交快照。分页只限制浏览结果，不能缩减外观和营地保存所需的完整所有权；新商品补录也不覆盖已有商品的价格、库存和上下架状态。素材版本更新后，初始化按同一人物、场景或物品的稳定身份刷新报价的资源引用，包含自建报价；名称、说明、价格、库存、上下架、软删除及订单快照保持原样。仅引用变化时递增商品版本，使旧购买确认重新核对；重复初始化不再递增。

家庭家具作为新素材版本加入目录，同时提供可购买的营地商品。启动时为已有账户补入明确标记需要补录的商品，使用稳定商品身份避免重复；已存在商品的价格、库存、上下架及软删除状态保持不变。家具不会自动赠送或摆入房屋，摆放空间与房屋规则见 [营地](ISLAND.md#角色活动与屋内展示)。

本次身体与六槽穿戴改造使用新的初始化结构，明确不提供旧人物映射、旧订单权益转换或旧数据迁移；开发数据库经用户授权后重置。这是已确认的实施范围，不是待验证的兼容能力；素材持久化规则也不代表旧人物订单可以自动转换。数据库结构不兼容时的安装处置见 [运行手册](../ENGINEERING/OPERATIONS.md)。
