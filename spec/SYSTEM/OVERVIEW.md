# 系统概览

## 产品与范围

成长营地供一个小朋友和家长共同使用。小朋友完成日常任务，记录文字、照片或录音，获得金币与钻石，再购买装扮、营地物件或家庭约定的奖励。家长使用同一账户，通过管理密码调整配置、纠正历史记录和兑现奖励。

系统强调鼓励和清晰反馈，不设置公开排行、惩罚或复杂等级。一个安装只有一个账户、一个小朋友；管理密码是额外授权，不构成另一种用户角色。系统不提供注册、多租户、离线写入或自动合并，也不设计跨标签页、跨设备实时同步。多个浏览器仍可同时访问同一服务，服务端必须正确处理并发和过期请求。

## 运行结构

生产运行一个 Go 进程、一份 SQLite 数据库和一组本地私有目录。React / TypeScript 构建为静态文件，由同一 Go 服务提供；HTTPS 入口代理整个站点。API、页面、受保护媒体及素材使用同源访问。

选择模块化单体和 SQLite，是因为单账户家庭场景无需独立数据库服务、消息队列或分布式锁。数据库事务、唯一约束和授权复核承担正确性；前端禁用按钮只是交互反馈，不能替代这些约束。

```text
浏览器页面
  → HTTP 路由、会话与请求校验
  → 账户 / 打卡 / 商店 / 成就 / 营地 / 留言服务
  → 短事务中的业务数据、钱包、流水与幂等收据

照片或录音
  → 私有上传与内容校验
  → 打卡事务关联媒体 ID
  → 鉴权读取与后台延迟清理
```

业务模块通过明确的 Go 服务和事务协作，共用账户授权、金额与日期规则。HTTP 层固定普通与管理入口的权限方式，并转换协议错误；React 页面处理草稿、加载和用户确认，不自行决定奖励或权限。

## 主流程与职责

| 用户目标 | 协作方式与规则归属 |
| --- | --- |
| 登录或维护账户 | CLI 建立账户或找回密码；网页维护姓名和密码。完整授权规则见 [账户](../FEATURES/ACCOUNT.md)。 |
| 完成任务、查看记录 | 服务端确定业务日期、次数和奖励，在一个事务中创建记录与经济事实；日周月与统计读取有效记录。见 [打卡与查询](../FEATURES/CHECKIN.md)。 |
| 购买、装扮和兑现 | 服务端确认商品、钱包与库存，订单保存成交快照和所有权；兑现需本次管理密码。见 [商店](../FEATURES/SHOP.md)。 |
| 获得或佩戴徽章 | 成就按有效记录、任务范围和排期计算，删除记录可能撤销资格。见 [成就](../FEATURES/ACHIEVEMENTS.md)。 |
| 建设和游玩营地 | 购买提供物品所有权，营地独立保存布局，并根据当天打卡取得活动资格。见 [营地](../FEATURES/ISLAND.md)。 |
| 保存照片或声音 | 文件先校验并进入私有目录，再由记录事务关联；失败和中断可恢复，解除引用后不能继续读取。见 [媒体](../FEATURES/MEDIA.md)。 |
| 浏览与家庭互动 | 页面围绕当前操作和跨日刷新；通用布局、声音与留言见 [界面与互动](../FEATURES/INTERFACE.md)。 |

上述专题拥有完整业务规则；跨模块的请求与存储约束分别由 [HTTP API](HTTP_API.md) 和 [数据与一致性](STORAGE.md) 维护。

## 启动、停止与持久化

维护命令和服务使用同一配置入口。`migrate` 显式执行迁移；`serve` 只校验数据库结构，不自动改库。服务完成数据库、媒体依赖和素材检查后才监听请求，并启动媒体清理。停止时先等待 HTTP 请求退出，再停止清理、关闭数据库。

数据库、上传文件、历史素材位于前端目录和发布目录之外。新程序可以替换，但已购素材与记录引用不能随旧发布目录被删除。媒体清理不负责素材回收。

配置中的相对路径以进程工作目录为准；业务时区固定为 `Asia/Taipei`。本地开发由 Vite 代理 Go API，生产只需要构建产物与媒体探测依赖，不运行前端开发服务器。

服务只支持本机磁盘上的单实例数据目录，不支持多机共享 SQLite。并发、恢复和迁移条件见 [数据与一致性](STORAGE.md)；安装、发布和排障步骤见 [运行手册](../ENGINEERING/OPERATIONS.md)。

## 验证边界

健康接口分别说明进程存活和依赖就绪，不能代替登录、打卡或购买验收。源码入口与测试候选只帮助定位，不代表本次已执行测试。

当前范围不包括备份功能、备份恢复演练和真机验证。自动化浏览器、文件数据库或本机发布验证，各自只能证明其实际边界；生产 HTTPS、systemd 和真实入口需在对应环境核验。验证选择与历史证据边界集中在 [测试指南](../ENGINEERING/TESTING.md)。
